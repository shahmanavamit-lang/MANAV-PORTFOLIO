03Mumbai PravaasUrban mobility · Fleet simulation+

A Mumbai fleet simulation combining traffic-aware routing, cooperative routing experiments, and wave-based vehicle deployment.

The repository describes a 50-vehicle simulation with fuel levels, medical priorities, live positions, and route estimates. Routing integrates OSRM and TomTom, with a separate multi-agent routing module.

Python · Routing APIs · Multi-agent simulationExplore repository ↗
04AI Parking SystemMachine learning · Decision support+

A parking-demand prototype that combines learned predictions with explicit capacity rules.

A FastAPI service applies time and weather features to a gradient-boosting model, then enforces overnight and lot-capacity rules. Training uses synthetic campus-demand data; this is a prototype, not a field-validated parking deployment.

Python · scikit-learn · FastAPI · Feature engineeringExplore repository ↗
05HisaabAI / Expense AnalyzerData analysis · Desktop application+

A desktop application for recording expenses and making spending patterns easier to understand.

Includes editable expense records, category and monthly reports, NumPy statistics, CSV export, and report sharing over a local network. The desktop interface is built in Tkinter.
