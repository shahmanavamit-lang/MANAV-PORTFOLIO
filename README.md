## Deploy

The file manav-portfolio-final.zip is the deployment package. Extract it and upload its contents to any static hosting provider. index.html must be at the site's root. No build command, Node server, environment variables, API keys, or dependency installation is required. All fonts, images, and PDFs are local.

If deploying from this source project, use public/ as the publish directory and leave the build command blank. npm start is available only as an optional local preview.
